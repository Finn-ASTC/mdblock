这是敌意宿主页。L1 层是普通特异性的宿主样式，文章块必须完全不受影响。 L2/L3 层是已知限制的演示，不是验收目标。

L1 · 普通宿主（验收断言在这一层）

全局 reset（*{margin:0;padding:0}、box-sizing:content-box）、 body 上的 letter-spacing:.35em / text-transform:uppercase / word-spacing:.5em / 花体字体， 以及加料的表格、代码、引用、列表样式。三个块分别是两个浅/深主题与一个 --hard-isolation 块。

L2/L3 · 已知限制（不参与断言，仅演示）

下面这一块被 .limit-demo .prose 包着，宿主在那里用了特异性更高的选择器 （.limit-demo .prose p）和 !important。它会被穿透 —— 这是 v1 的已知边界，不是缺陷隐瞒：命名空间 CSS 无法胜过任意特异性的宿主规则， 而 --hard-isolation 的 all: revert 只作用于根元素自身。
